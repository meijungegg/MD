# 十月突破日記

2026 年 10 月「突破行動」每日日記練習網站。

- 每天一個提問＋一個行動，分成紫、藍、紅、綠、黃、橙六種驅動力
- 記錄回答、行動狀態、行動紀錄、心情、一句話收穫
- 月曆總覽、月底回顧（統計、心情曲線、驅動力完成度、31 句收穫、四題反思）
- 一鍵複製「AI 回顧指令」，貼到 Claude 等 AI 對話框做月度回顧

## 資料存在哪裡

日記只存在學員自己裝置的瀏覽器裡（localStorage），不會上傳，老師和其他學員都看不到。
換裝置或清除瀏覽器資料之前，請在「月底回顧」頁下載備份，再到新裝置匯入。

## 發布到 GitHub Pages

1. 在 GitHub 建立一個 Public repository，例如 `october-journal`
2. Add file → Upload files，上傳這個資料夾裡的 `index.html` 和 `README.md`
3. Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save
4. 等 1–2 分鐘，網址會是 `https://<你的帳號>.github.io/october-journal/`
